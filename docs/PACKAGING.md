# Local macOS Package

Status: self-contained local build using the installed Godot 4.7.2 editor runtime. This is a practical Mac delivery path while official export templates are not installed. It is larger than a template export because it embeds the full unmodified Godot application.

From the project directory, run `bash tools/build_macos.sh`; from elsewhere, give the script's absolute path. Run `bash tools/build_macos.sh --list-assets` first to inspect the exact staged runtime-asset list without exporting or replacing the existing app. By default the builder reads `/Users/quan/Downloads/Godot.app`; set `GODOT_APP=/absolute/path/to/Godot.app` to use another installed Godot 4.7.2 bundle. It needs built-in macOS `ditto`, `codesign`, `rsync`, and Xcode command-line `clang` through `xcrun`. No paid account, export template, network download or registration is required.

The output is the ignored `build/1944 Town Mission.app`. Double-click or `open` that app. The outer application contains a small launcher which locates its own bundled Godot binary and `Game.pck`; neither the original project directory, the original Downloads app nor the current working directory is needed after packaging. The launcher and outer app receive an ad-hoc signature. This is a local build, not Apple notarization for broad distribution. `Contents/Resources/BUILD_INFO.txt` records the build time, source Git commit and dirty state, PCK SHA-256 and Godot version. Import/export logs stay under `build/packaging-logs/` for review even if a build fails.

The PCK is exported from a strict game-only staging project. It contains project settings and recursively selected runtime files from `scenes/`, `scripts/` and `assets/`, including environment textures and Godot-ready GLB models. The allowlist covers scenes, scripts, materials, models, textures, audio, fonts and their authored `.import`/UID sidecars; orphan sidecars are removed. Raw `.fbx`, `.blend`/`.blend1`, archives and every `source/` or `previews/` directory are excluded. The local `reference/` research directory, documentation, tests, build scripts, Git data, editor caches and credentials never enter staging. The build log retains `asset-manifest.txt` for review. Missing Sten or any of the three integrated character GLBs fails the build instead of shipping placeholder visuals. The builder copies Lotnik's required Sten CC BY 3.0 attribution, the MakeHuman-derived characters' CC0 provenance, Godot's MIT license and Poly Haven's license record to `Contents/Resources/ThirdPartyLicenses/`. The original installed Godot.app is copied without changing its executable or bundle contents.
